# Raqeeb | رقيب

**A pre-click scam link checker.** Paste a link, or check the page you are on, and get a risk verdict (Safe, Suspicious or Dangerous), a 0-100 risk score and plain-language reasons, before you click.

Raqeeb analyses the link text only and never visits the site, so results are instant and checking a dangerous link is safe.

Built for the challenge: *Detecting Fraudulent Links and Websites Used in Cybercrimes and Financial Fraud.*

## Features
- **Explainable results.** Every verdict comes with the top reasons, for example brand impersonation, a risky domain ending or a raw IP address.
- **Hybrid detection.** A Random Forest model (60%) combined with transparent rule-based checks (40%).
- **Bilingual dashboard.** Arabic and English with a full right-to-left layout.
- **Incident feed and counters.** Live log of checks and community scam reports.
- **Chrome extension.** Checks the current tab through the local Raqeeb server.

## How it works
1. `features.py` extracts 24 URL features: length, hyphens, digits, `@`, IP host, brand-in-wrong-domain, look-alike characters (such as `paypa1`), URL shorteners, risky domain endings, punycode and more.
2. `train.py` trains a Random Forest and prints accuracy, a confusion matrix and feature importances.
3. `predict.py` computes the final score, caps trusted brand domains at a low score, and turns each triggered rule into a plain-language reason. An optional `deep=true` mode adds a WHOIS domain-age check.
4. `app.py` and `static/index.html` provide the FastAPI backend and the web dashboard.

## Run it locally
Requires Python 3.10 or newer.

```bash
pip install -r requirements.txt
python train.py
python -m uvicorn app:app --reload
```

Then open http://127.0.0.1:8000. On Windows you can also double-click `start_raqeeb.bat`.

### Chrome extension
1. Start the server.
2. Open `chrome://extensions` and turn on Developer mode.
3. Click Load unpacked and select the `extension/` folder.

### API
| Method | Endpoint | Purpose |
| --- | --- | --- |
| GET | `/api/check?url=...` | Analyse a link |
| POST | `/api/report` | Report a link as a scam |
| GET | `/api/reports` | Recent community reports |
| GET | `/api/stats` | Counters and recent checks |
| POST | `/api/reset` | Clear stored checks and reports |

## Training data
The repository includes a synthetic dataset (`data/synthetic_urls.csv`, generated by `make_dataset.py`) so the project runs offline. Metrics from it are for demonstration only. For a real evaluation, save a labelled phishing URL dataset as `data/urls.csv` with `url` and `label` columns and run `python train.py` again.

## Limitations
- Analysis is based on the link text only. It cannot see page content, so a clean-looking link can still lead to a scam. "Safe" means no warning signs were found, not a guarantee.
- The trusted-domain list is small.
- Search-engine result and Maps listing checks are not implemented yet.
